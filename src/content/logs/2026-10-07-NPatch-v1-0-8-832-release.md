## 原文

fix(manager): 修復模組掃描受限丟失、Companion 激活推送與多選 APK 打包白屏
- 修正 hasRealAppListAccess 假陽性檢測，被系統攔截包列表時不再誤判為已授權
- ConfigManager.updateModules 增加受限掃描與本機 APK 存在性防護，防止已配置模組被清空
- fetchAppList 掃描時自動合併資料庫既有模組，避免受限環境下模組列表消失
- 解除 AppDetailScreen 與 ModuleManageViewModel 針對 Shizuku 的硬性門檻，支援 ContentProvider 雙軌推送
- ModuleService 於宿主查詢模組時補齊 pushToCompanionsAsync，恢復後台 QA/QF/HookVip 激活展示
- ModuleScopeSyncStore 追蹤名單對齊 SQLite 資料庫，增強自救重推可靠性
- NewPatchScreen 與 NeoPackageManager 支援解析多個獨立 Base APK 並提供選單引導，補齊過渡載入與錯誤彈窗以防止全白屏

## 简体中文

fix(manager): 修复模块扫描受限丢失、Companion 激活推送与多选 APK 打包白屏
- 修正 hasRealAppListAccess 假阳性检测，被系统拦截包列表时不再误判为已授权
- ConfigManager.updateModules 增加受限扫描与本机 APK 存在性防护，防止已配置模块被清空
- fetchAppList 扫描时自动合并数据库既有模块，避免受限环境下模块列表消失
- 解除 AppDetailScreen 与 ModuleManageViewModel 针对 Shizuku 的硬性门槛，支持 ContentProvider 双轨推送
- ModuleService 于宿主查询模块时补齐 pushToCompanionsAsync，恢复后台 QA/QF/HookVip 激活展示
- ModuleScopeSyncStore 追踪名单对齐 SQLite 数据库，增强自救重推可靠性
- NewPatchScreen 与 NeoPackageManager 支持解析多个独立 Base APK 并提供菜单引导，补齐过渡加载与错误弹窗以防止全白屏
